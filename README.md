A [make.fun](https://make.fun/c/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) entry: one fortune cookie line for a crypto trader who has just been liquidated. The program writes the fortune to `/output/entry.txt`.

> A great fortune awaits you — unfortunately, it is the same one you just lost to leverage.

17 words, one line, deterministic — the same bytes on every run. No network, no randomness.

Run it with Node 22+:

```sh
node main.ts
cat /output/entry.txt
```
